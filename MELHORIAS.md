# Bozó de Mesa — lista de melhorias

Lista combinada para deixar o jogo com cara de app profissional (análise de 28/10/2026).
Marque `[x]` quando ficar pronto. A ordem é a sugerida (mais importante primeiro).

## Já feito
- [x] Lápis riscando o papel ao marcar, atualização obrigatória, botão "Voltar ao início" no fim, feltro felpudo e copo de couro — versão 1.0.45
- [x] Sons gravados de dados (copo chacoalhando, dados caindo no feltro) — versão 1.0.43
- [x] Vibração (chacoalhar, dados caindo, guardar dado, marcar, General) e botão para desligar — versão 1.0.43
- [x] Só marcador: a vez passa sozinha e a lista fica na ordem da jogada — versão 1.0.41
- [x] Tela fixa (não rola nem "puxa"), copo à direita, painel do copo maior no tablet, placar no meio da mesa — versão 1.0.39
- [x] Tela inicial nova: abertura com três botões e jogadores em volta de uma mesinha — versão 1.0.37

## Próximos passos
1. [ ] **Confirmação ao cortar** — "Cortar General? Vale zero". Evita o erro bobo sem mudar a regra de não poder desfazer.
2. [ ] **Testes automáticos guardados no projeto** — os testes de tela e de partida rodando sozinhos a cada mudança, para nada quebrar sem ninguém perceber.
3. [ ] **Fotos novas da loja + Play Store** — tirar capturas da tela nova e seguir o `PUBLICAR.md` (passos 3 a 7). Recomendação: grátis e sem anúncios no começo.
4. [ ] **Dados mais caprichados** — dados com sombra, rolando mais solto (o copo de couro já foi feito).
5. [ ] **Mini tutorial na primeira vez** — 3 ou 4 telas: guardar dados, pedir baixo, "de boca" vale mais.
6. [ ] **Regras com desenhos** — exemplos com dados desenhados (ex.: Full = 3 iguais + 2 iguais) em vez de só texto.
7. [ ] **Níveis do computador** — fácil, médio e difícil, e velocidade do bot (normal ou rápido).
8. [ ] **Tela de ajustes** — som, vibração, velocidade do bot, copo à esquerda (canhotos) e "regras da casa" (variações do bozó de cada lugar).
9. [ ] **Letras maiores no tablet** — com 4 jogadores, os nomes das casas da cartela ficam pequenos; clarear também os textos cinza.
10. [ ] **Estatísticas** (opcional) — Generais feitos, maior pontuação, vitórias contra o bot.
11. [ ] **Versão em espanhol** (opcional) — para alcançar mais gente na loja.
12. [ ] **Organizar o código** (bastidores) — o jogo é um arquivo único grande; separar em partes facilita mudanças futuras.
